# 바이낸스 7팀 모의매매 대시보드

7개 팀이 가상 자금으로 운영하는 모의매매(페이퍼 트레이딩) 결과를 한 화면에서 보는 정적 대시보드입니다.
실제 자금·실제 주문은 포함되지 않으며, 계좌번호나 개인정보도 담기지 않습니다.

- 보기: https://areeahri-create.github.io/trading-dashboard/
- 구조: `index.html` 한 파일. 데이터 스냅샷이 파일 안에 들어 있어 열기만 하면 바로 표시됩니다.
- 갱신: 새 스냅샷이 준비되면 `index.html`을 교체해 올립니다. 링크는 그대로 두고 새로 고침만 하면 됩니다.
- 화면: 팀별 자산·손익, 진행 중/청산 거래, 전략별 성과, 자산 곡선, 일별 캘린더, 팀 전달사항.
